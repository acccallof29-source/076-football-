# Football Touch — نمونه مسابقه قابل‌کنترل

این پروژه یک نمونه اولیه واقعی و قابل‌بازی فوتبال دوبعدی از نمای بالا است؛ نه صرفاً داشبورد مدیریتی.

## کنترل‌ها
- موبایل: جوی‌استیک سمت چپ برای حرکت؛ دکمه «پاس»؛ دکمه «شوت»؛ «تعویض» برای انتخاب نزدیک‌ترین بازیکن.
- رایانه: WASD یا کلیدهای جهت برای حرکت، Space پاس، Enter شوت، Tab تعویض بازیکن.
- زمان مسابقه در نمونه سریع‌شده است.

## اجرا
پروژه را با Godot 4.4.1 باز کن و صحنه `scenes/main.tscn` را اجرا کن.

## ساختار
- `scripts/match.gd`: زمین، بازیکنان، توپ، کنترل‌ها، هوش مصنوعی ساده و امتیاز
- `scenes/main.tscn`: صحنه اصلی
- `.github/workflows/build-apk.yml`: تلاش برای خروجی APK اندروید در GitHub Actions

## محدودیت‌های این نمونه
این فقط اثبات مفهوم کنترل مستقیم است: توپ‌گیری، پاس و شوت ساده‌اند؛ برخوردها، قوانین کامل فوتبال، دروازه‌بان هوشمند، انیمیشن‌های اسکلتی، داور، آفساید، خطا، لیگ و دیتابیس واقعی هنوز پیاده‌سازی نشده‌اند. نام و نشان باشگاه‌ها و بازیکنان رسمی نیز در این نمونه استفاده نشده است.
